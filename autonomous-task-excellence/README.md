# autonomous-task-excellence

複雑な多段階タスクを自律的に完遂するための行動原理スキルです。

## 概要

エージェントが「指示待ちの作業者」ではなく「結果に責任を持つ担当者」として振る舞うための規範を定義します。タスク分解、自己検証、次アクション判断の3つが中核です。

## いつ使うか

- 新規サービス構築や本番デプロイなど、複数ステップにまたがる作業
- 実行環境が不安定で、失敗時のフォールバックが必要なとき
- 「証拠なき完了報告」を防ぎたいとき

## 使い方

### 1. スキルの有効化

Cursor のスキル設定で `autonomous-task-excellence/` ディレクトリをスキルとして登録します。

### 2. プロンプト例

```
新規 API サービスを構築して。認証・DB・エンドポイント・テストまで完遂して。
```

```
本番デプロイを進めて。各ステップで動作確認の証拠を示してから次に進んで。
```

```
このタスクを分解して、検証可能な粒度のタスクリストを作ってから着手して。
```

### 3. エージェントの振る舞い

スキル有効時、エージェントは以下を実践します。

1. **着手前** — あいまいな仕様を質問で潰し、既存資産を調査し、依存関係順のタスクリストを作成
2. **実行中** — 失敗時に同じ手を繰り返さず、経路を切り替える
3. **報告前** — 「実行した」と「動作を確認した」を区別し、証拠付きで報告

## ファイル構成

| ファイル | 内容 |
|----------|------|
| `SKILL.md` | 行動原理の全文（タスク分解・自己検証・次アクション判断） |
| `README.md` | このファイル |
