# git-workflow

Git 操作・コンフリクト解消・PR 作成のワークフロースキルです。

## 概要

変更のコミット（Conventional Commits）、リモート同期、コンフリクト解消、プッシュ、GitHub CLI による PR 作成までを一貫して扱います。

## いつ使うか

- 変更をコミットして PR を作りたい
- マージコンフリクトを解消したい
- Git 操作の一連の流れを任せたい

## 使い方

### 1. スキルの有効化

Cursor のスキル設定で `git-workflow/` ディレクトリをスキルとして登録します。

### 2. 前提条件

- GitHub CLI (`gh`) がインストール・ログイン済みであること

### 3. プロンプト例

```
変更をコミットして PR を作成して。
```

```
main とのコンフリクトを解消して。
```

```
git status を確認して、適切なコミットメッセージでコミットして。
```

### 4. エージェントの手順

1. `git status` / `git diff` で変更を把握
2. Conventional Commits 形式でコミット
3. `git fetch` + マージでリモート同期、コンフリクト解消
4. `git push` でリモート反映
5. `gh pr create` で PR 作成、マージ可能性を確認

### 5. 注意事項

- **push や PR 作成前にユーザーの承諾を得る**（スキル内の指針）
- `main` / `master` への直接コミットは避け、トピックブランチの作成を提案
