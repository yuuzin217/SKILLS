# session-save

現在のセッション作業内容を Markdown 要約として保存するスキルです。

## 概要

完了した作業、現在のステータス、次セッションへの引き継ぎ事項を構造化した Markdown ファイルとして出力します。

## いつ使うか

- セッション終了前に作業内容を記録したい
- 次のエージェントセッションへの引き継ぎ資料を作りたい
- 長期タスクの進捗をファイルに残したい

## 使い方

### 1. スキルの有効化

Cursor のスキル設定で `session-save/` ディレクトリをスキルとして登録します。

### 2. プロンプト例

```
セッション要約を作成して。
```

```
今の作業内容を次のセッション用にまとめて保存して。
```

```
引き継ぎ用の session summary を生成して。
```

### 3. 出力先

1. `<workspace>/.sessions/session_summary_<YYYY-MM-DD>.md`（優先）
   - **1日1ファイル**: 同日のファイルが既にあれば、末尾に新しいセッションブロックを追記
   - 初回保存時のみファイルを新規作成
2. フォールバック: 会話アーティファクトディレクトリ

### 4. 要約の構成

```markdown
# セッション作業要約 (Session Summary - <Date>)

## セッション 1 (<HH:MM> / conversation: <id>)

### 1. 完了した作業 (Work Accomplished)
### 2. 現在のステータス (Current Status)
### 3. 次のセッションへの引継ぎ事項 (Next Steps)
```

同日に2回目以降の保存を行う場合は、`## セッション 2` のように番号付きブロックを追記します。

### 5. エージェントの手順

1. `git status` / `git diff` で変更を収集
2. ビルド・テストの結果を確認
3. 当日の要約ファイルの有無を確認（あれば追記、なければ新規作成）
4. 上記フォーマットで要約を生成・保存
5. 生成ファイルへのリンクをユーザーに提示

## ファイル構成

| ファイル | 内容 |
|----------|------|
| `SKILL.md` | 要約生成手順の全文 |
| `README.md` | このファイル |

## 関連スキル

- `session-load` — 保存した要約の読み込みと作業再開
