# animation-vocabulary

Web アニメーション・モーション効果の用語逆引きスキルです。

## 概要

「ポップオーバーが開くときのバウンスするやつ」「iOS のゴム紐スクロール」など、曖昧な表現を正確な用語（Pop in、Rubber-banding など）に変換します。効果の**命名**が目的であり、設計・実装は対象外です。

## いつ使うか

- 「あれなんていう名前？」とモーション効果の用語を知りたい
- AI やデザイナーに正確な用語で指示したい
- アニメーションの説明を専門用語に置き換えたい

## 使い方

### 1. スキルの有効化

Cursor のスキル設定で `animation-vocabulary/` ディレクトリをスキルとして登録します。

### 2. プロンプト例

```
ドロップダウンが開くときのあの弾む感じ、正式名称は何？
```

```
スクロールが端で跳ね返る iOS のあの効果、用語で教えて。
```

```
「要素が順番にフェードインする」アニメーションの名前は？
```

### 3. 出力形式

エージェントは次の形式で回答します。

```
**Stagger** — Animate several items one after another with a small delay between each, creating a cascade.
```

複数候補がある場合は、最適な用語を先頭に、代替を 1〜2 件併記します。

### 4. エージェントの方針

- ユーザーの「感覚的な説明」から意図を読み取る
- 用語集の定義をそのまま引用する（言い換えしない）
- 近い用語が複数ある場合は違いを説明して選べるようにする
