# クリーンコード設計スキル

このスキルは、コードの設計やリファクタリングにおいて、UIとロジックの分離やクリーンな階層化を推進するための手順です。

## 手順

1. **コードの現状分析**
   - 修正対象のファイル（特にUIコンポーネントやページ）に、ビジネスロジックやデータ加工処理がインラインで記述されていないか確認する。
   - 単一責任の原則（SRP）に違反している箇所（例：UIコンポーネントがテキスト正規化や複雑なアルゴリズムを持っているなど）を特定する。

2. **関心の分離と切り出し**
   - 特定したロジックを、再利用可能な関数として `lib/utils.ts` やドメイン専用のモジュールに切り出す。
   - 切り出す関数は、副作用のない純粋関数（Pure Function）にすることを目指す。

3. **UI側のリファクタリング**
   - 切り出した関数をUIコンポーネントでインポートして使用するように書き換える。
   - UIコンポーネントコードがシンプルになり、宣言的（Declarative）になっていることを確認する。

4. **テストによる検証**
   - リファクタリングによって既存の機能が壊れていないか、テストを実行して検証する。
   - 必要に応じて、切り出した関数に対する単体テストを追加する。
