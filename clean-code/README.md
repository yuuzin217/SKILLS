# clean-code

クリーンコード原則に基づくリファクタリング・設計スキルです。

## 概要

UI とロジックの分離、単一責任の原則（SRP）、DRY を適用して、保守しやすいコード構造を実現します。

## いつ使うか

- UI コンポーネントにビジネスロジックが混在している
- リファクタリングで関心の分離を進めたい
- コードレビューで設計改善を依頼したい

## 使い方

### 1. スキルの有効化

Cursor のスキル設定で `clean-code/` ディレクトリをスキルとして登録します。

### 2. プロンプト例

```
このコンポーネントをクリーンコードの原則でリファクタリングして。UIとロジックを分離して。
```

```
ページコンポーネント内のデータ加工処理を lib/ に切り出して。
```

```
SRP に違反している箇所を特定して、リファクタリング案を出して。
```

### 3. エージェントの手順

1. 対象ファイルの現状分析（インラインロジック、SRP 違反の特定）
2. ロジックを `lib/utils.ts` やドメインモジュールへ切り出し
3. UI コンポーネントを宣言的に書き換え
4. テストで既存機能の破壊がないか検証
