# apple-design

Apple のインターフェース設計・流体モーション原則を Web 向けに適用するスキルです。

## 概要

WWDC 2018「Designing Fluid Interfaces」を基に、ジェスチャー駆動 UI、スプリングアニメーション、ドラッグ/スワイプ/シート、モメンタムと割り込み可能な遷移、半透明マテリアル、タイポグラフィ、reduced-motion などを Web プラットフォーム向けに解説します。

## いつ使うか

- Apple 風のジェスチャー駆動 UI を実装・レビューしたい
- スプリングアニメーションやドラッグ操作の設計を相談したい
- インタラクションの「物理的な自然さ」を高めたい

## 使い方

### 1. スキルの有効化

Cursor のスキル設定で `apple-design/` ディレクトリをスキルとして登録します。

### 2. プロンプト例

```
このシートのドラッグ操作を Apple 風の流体インターフェースにして。
```

```
ボタンのフィードバックを pointer-down 時点で即座に出すように改善して。
```

```
スプリングアニメーションで、ジェスチャーの速度を引き継ぐようにして。
```

```
reduced-motion に対応したアニメーションに修正して。
```

### 3. 中核原則

> インターフェースは、画面上の現在値から動き始め、ユーザーの速度を引き継ぎ、モメンタムを前方に投影し、いつでも掴んで逆転できるときに「生きている」と感じる。

主なルール:

1. **Response** — pointer-down で即座にフィードバック、レイテンシの排除
2. **Motion** — スプリングによる速度引き継ぎと割り込み可能性
3. **Feedback** — 連続的なインタラクション中の 1:1 UI 更新
4. **Restraint** — 過剰なアニメーションを避ける
