# session-load

前セッションの作業コンテキストを読み込んで再開するスキルです。

## 概要

`session_summary_*.md` を探して読み込み、前回の作業内容・Git 状態・次のステップを復元して開発を継続します。

## いつ使うか

- 前のセッションの続きから作業を再開したい
- セッション要約をインポートしてコンテキストを復元したい
- 別のエージェントセッションに作業を引き継ぎたい

## 使い方

### 1. スキルの有効化

Cursor のスキル設定で `session-load/` ディレクトリをスキルとして登録します。

### 2. 前提条件

`session-save` スキルで生成されたセッション要約ファイルが存在すること。

### 3. プロンプト例

```
前のセッションを読み込んで、作業を再開して。
```

```
session_summary をインポートして、続きから進めて。
```

```
前回どこまで進んだか確認して、次のステップを提案して。
```

### 4. エージェントの手順

1. セッション要約ファイルを検索（優先順位）:
   - `<workspace>/.sessions/session_summary_<YYYY-MM-DD>.md`（1日1ファイル形式）
   - レガシー: `<workspace>/.sessions/session_summary_<YYYY-MM-DD>_<id>.md`
   - `<workspace>/session_summary.md`
   - アーティファクトディレクトリ内
2. 要約を読み込み、完了作業・Git 状態・PR 状況を把握
   - 同日に複数セッションがある場合は、**最後の `## セッション` ブロック**を最新コンテキストとして優先
3. 「次のステップ」セクションから即座に着手すべきタスクを特定
4. ユーザーに復元完了を報告し、次のアクションを確認

## ファイル構成

| ファイル | 内容 |
|----------|------|
| `SKILL.md` | セッション復元手順の全文 |
| `README.md` | このファイル |

## 関連スキル

- `session-save` — セッション要約の生成（ペアで使用）
