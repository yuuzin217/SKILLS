# html-explain

コード・設計・アーキテクチャの説明を Markdown ではなく **自己完結 HTML** として出力するスキルです。

## 概要

技術説明の主成果物を `.html` に統一し、ブラウザで読みやすい単体ドキュメントにします。チャットにはパスと短い要約だけを返し、本文の長文 Markdown は書きません。

## いつ使うか

- 「HTML で説明して」「md じゃなくて html で出して」
- コード解説・設計メモ・アーキテクチャ説明をブラウザで読みたい
- 引き継ぎやレビュー用の単体ドキュメントが欲しい

## 使い方

### 1. スキルの有効化

Cursor のスキル設定で `html-explain/` ディレクトリをスキルとして登録します。

### 2. プロンプト例

```
この認証フローを HTML で説明して。
```

```
/html-explain
payments のリトライ設計をブラウザで読める HTML にして。
```

```
md ではなく html で、このモジュールの責務とトレードオフをまとめて。
```

### 3. エージェントの方針

1. **主成果物は `.html`** — チャットに長文 Markdown を書かない
2. **自己完結** — `template.html` を土台に、単体で表示できる HTML を書く
3. **Why を厚く** — 挙動の羅列より設計理由・制約・却下案
4. **短いチャット返信** — ファイルパスと 1〜3 行の要約のみ

## ファイル構成

| ファイル | 内容 |
|----------|------|
| `SKILL.md` | 出力ルール・構成・品質チェックの全文 |
| `template.html` | 共通の HTML/CSS 骨組み |
| `README.md` | このファイル |
