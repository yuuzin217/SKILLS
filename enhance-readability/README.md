# enhance-readability

コードの可読性向上とドキュメント付与スキルです。

## 概要

「何をしているか」ではなく「なぜその実装になったか」という意図を重視して、コメントや JSDoc/GoDoc を追加します。

## いつ使うか

- コードの意図を明確にしたい
- ドキュメントコメントを追加したい
- 可読性向上のためのリファクタリングを依頼したい

## 使い方

### 1. スキルの有効化

Cursor のスキル設定で `enhance-readability/` ディレクトリをスキルとして登録します。

### 2. プロンプト例

```
この関数に「なぜ」を重視したコメントを付けて。
```

```
/enhance-readability
このサービス層のコードの可読性を改善して。
```

```
JSDoc 形式で引数・戻り値・エラー条件をドキュメント化して。
```

### 3. エージェントの方針

1. **Why を記述** — 実装の背景・制約・選択理由をコメントに含める
2. **標準形式を遵守** — TypeScript は JSDoc/TSDoc、Go は GoDoc 形式
3. **リファクタリング提案** — マジックナンバーの定数化、長い関数の分割
4. **盲点の指摘** — 境界条件の漏れやパフォーマンス懸念に `[TODO]` / `[FIXME]` を付与
